# بوت تيليجرام لعزل خلفيات الصور بالذكاء الاصطناعي 🚀

مشروع متكامل لعزل خلفيات الصور والمنتجات عبر تيليجرام، مستوحى ومبني على تقنيات العزل المستخدمة في مشروع `nama/kayan` لمعالجة صور الأزياء والمتاجر الإلكترونية (نون، جوميا، وأمازون).

يدعم التشغيل **المحلي (Long Polling)** أو النشر كـ **Serverless Webhook على منصة Vercel** (بنفس هيكلية مشروع `bot_admagh`).

---

## 🌟 المميزات الرئيسية

1. **دقة عزل فائقة بدون عيوب:**
   - استخدام معالجة الفراغات الداخلية (**Binary Fill Holes**) لحماية تفاصيل وأقمشة الملابس من التثقيب العشوائي.
   - تنعيم الحواف (**Gaussian Feathering**) لمنع التسنن وظهور الأطراف بمظهر طبيعي ومحترف.

2. **موديلين متخصصين بالذكاء الاصطناعي:**
   - **موديل الأزياء والملابس (`u2net_human_seg`):** مخصص للعبايات، الفساتين، الطرح، الموديلز، والأشخاص.
   - **موديل المنتجات العامة (`u2net`):** مخصص للمنتجات الصلبة، الأحذية، الحقائب، الساعات، والأجهزة.

3. **أنماط مخرجات متعددة:**
   - **كلاهما (الافتراضي):** يرسل صورة بخلفية بيضاء للمعاينة والتجارة + ملف PNG مفرغ شفاف كامل الجودة.
   - **خلفية بيضاء:** خلفية بيضاء نقية (`#FFFFFF`) مطابقة لمعايير منصات التجارة الإلكترونية.
   - **خلفية شفافة (PNG):** ملف مفرغ تماماً للاستخدام المباشر في برامج التصميم والفوتوشوب.

4. **لوحة تحكم وأزرار تفاعلية:**
   - أزرار تحت كل صورة لتحويل الخلفية إلى (أبيض، أسود، شفاف) أو تبديل الموديل بضغطة زر.
   - أمر `/settings` للتحكم في الإعدادات وحفظها لكل مستخدم على حدة.

5. **دعم كامل لدقة الصور:**
   - يدعم الصور العادية المضغوطة.
   - يدعم إرسال الصور كملف (**Send as Document**) للحفاظ على دقة الكاميرا الأصلية 100%.

## 🚀 النشر على استضافة Vercel

تم تجهيز المشروع بنفس بنية `bot_admagh` تماماً ليقبل النشر الفوري على Vercel:

### 1️⃣ خطوات الرفع والنشر:
1. ارفع المشروع إلى مستودع جديد على حسابك في GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/remove_bg_bot.git
   git branch -M main
   git push -u origin main
   ```
2. ادخل على لوحة تحكم [Vercel Dashboard](https://vercel.com) واضغط **Add New Project** ثم اختر المستودع.
3. في خانة **Environment Variables** أضف:
   - `BOT_TOKEN`: `8631248092:AAFkTZu7eDgiBADhVc5LSheDAv9-gzWVrIA`
   - `DEFAULT_MODEL`: `u2net_human_seg`
   - `DEFAULT_OUTPUT_MODE`: `both`
4. اضغط **Deploy**.

### 2️⃣ تفعيل الويب هوك (Webhook):
بعد انتهاء النشر وظهور رابط موقعك على فيرسيل (مثال: `https://remove-bg-bot.vercel.app`):
- **الطريقة الأسهل:** افتح الرابط في المتصفح وستجد لوحة تحكم تفاعلية مع زر **"⚡ تفعيل الويب هوك (Set Webhook)"**؛ اضغط عليه ليتم ربط البوت فوراً!
- أو افتح الرابط التالي مباشرة في المتصفح:
